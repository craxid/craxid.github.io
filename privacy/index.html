Data yang Kami Kumpulkan

Situs ini tidak meminta, menyimpan, atau memproses data pribadi pengunjung secara langsung. Tidak ada formulir pendaftaran, tidak ada akun, dan tidak ada pelacakan individual yang kami lakukan sendiri.

Cookie

Situs ini menggunakan penyimpanan lokal browser (localStorage) hanya untuk mengingat preferensi tema terang/gelap pilihan Anda. Data ini tersimpan di perangkat Anda sendiri dan tidak pernah dikirim ke server kami.

Google AdSense dan Cookie Iklan

Situs ini menayangkan iklan melalui Google AdSense. Google dan vendor pihak ketiganya menggunakan cookie — termasuk cookie DART — untuk menayangkan iklan berdasarkan kunjungan Anda ke situs ini dan situs lain di internet.

Anda dapat memilih untuk tidak menerima cookie DART dengan mengunjungi kebijakan iklan Google. Penggunaan cookie oleh Google tunduk pada kebijakan privasi Google.

Tautan ke Situs Lain

Situs ini memuat tautan ke situs eksternal (misalnya GitHub, Telegram, dan CDN). Kami tidak bertanggung jawab atas praktik privasi situs-situs tersebut.

Aplikasi Mousike dan YouTube API Services

Bagian ini berlaku untuk aplikasi Android Mousike, di luar kebijakan untuk situs ini di atas.

Mousike menggunakan YouTube API Services untuk fitur "Impor dari YouTube". Dengan izin pengguna, aplikasi mengakses data berikut dari akun YouTube pengguna melalui YouTube Data API v3, dengan cakupan akses baca-saja (youtube.readonly):

  • daftar playlist yang dibuat pengguna,
  • isi dari playlist tersebut,
  • daftar video yang disukai pengguna (playlist "Musik yang disukai").

Data tersebut digunakan hanya untuk membuat playlist lokal di dalam aplikasi pada perangkat pengguna, atas permintaan pengguna sendiri. Token akses YouTube hanya disimpan sementara di memori selama proses impor berlangsung dan tidak pernah ditulis ke penyimpanan permanen.

Data hasil impor, yaitu judul video, nama kanal, durasi, dan tautan gambar sampul, tersimpan sebagai playlist lokal di perangkat pengguna sebagai bagian dari data aplikasi. Data tersebut tidak diunggah ke server pengembang, tidak dijual, dan tidak dibagikan kepada pihak ketiga. Mousike tidak mengubah, menambah, atau menghapus data apa pun di akun YouTube pengguna.

Dengan menggunakan fitur ini, pengguna juga tunduk pada Persyaratan Layanan YouTube dan Kebijakan Privasi Google. Pengguna dapat mencabut akses Mousike ke akun Google kapan saja melalui halaman izin akun Google. Setelah akses dicabut, fitur impor tidak dapat digunakan sampai pengguna memberikan izin lagi.

Masuk dengan Google dan Sinkronisasi di Mousike

Mousike menawarkan pilihan masuk dengan akun Google untuk menyinkronkan pustaka musik pengguna (playlist lokal, lagu yang disukai, dan riwayat putar) antarperangkat melalui layanan Supabase. Data yang diterima dari Google untuk keperluan ini terbatas pada nama, alamat email, dan foto profil akun, yang dipakai hanya untuk mengidentifikasi akun pemilik pustaka. Pengguna dapat keluar kapan saja dari dalam aplikasi, dan sesi masuk di perangkat akan dihapus.
