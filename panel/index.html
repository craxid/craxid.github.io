    Tempel token API & Zone ID sekali — tersimpan di browser ini saja, tidak pernah masuk ke kode situs.

    Cara mendapatkan token & Zone ID
    1. Buka dash.cloudflare.com → profil → API Tokens → Create Token.
    2. Pilih template Read analytics atau custom dengan izin Zone → Analytics → Read untuk zona hxa.my.id.
    3. Salin tokennya, tempel di kolom atas.
    4. Zone ID: buka domain hxa.my.id di dashboard Cloudflare, lihat kolom kanan bawah halaman Overview.
