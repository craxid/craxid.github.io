    Cloudflare

    Data diambil lewat Worker milikmu sendiri — token API tersimpan aman di Worker sebagai Secret, tidak pernah lewat browser.

    Cara menyiapkan Worker (sekali saja)
    1. Buka dash.cloudflare.com → Workers & Pages → Create Worker → Deploy.
    2. Klik Edit code, hapus isi bawaannya, tempel kode worker dari saya, lalu Save and deploy.
    3. Buka Settings → Variables: tambah Secret bernama CF_API_TOKEN (isi token API-mu), dan Variable bernama CF_ZONE_ID (isi Zone ID hxa.my.id).
    4. Salin URL *.workers.dev milik worker itu, tempel di kolom atas.
