Setelan Lanjutan

Jaga layar tetap hidup

Saat aktif, layar perangkat dijaga tetap menyala selama musik diputar — berguna saat mengikuti lirik. Konsumsi baterai lebih tinggi saat fitur ini aktif.

Kualitas audio

Pilih kualitas audio yang dipakai saat sumbernya LOCAL. Berlaku mulai lagu berikutnya.

Format unduhan

Pilih format file saat mengunduh lagu. M4A memakai audio asli tanpa konversi (kualitas tertinggi); MP3 dikonversi ke 256 kbps agar kompatibel dengan semua pemutar.

YouTube Data API key

Sumber pencarian bawaan memakai instance publik (gratis, ketersediaan tidak terjamin). Untuk hasil yang konsisten, gunakan YouTube Data API key pribadi — tersimpan lokal di perangkat ini dan tidak dikirim ke mana pun. Cara membuat: Google Cloud Console → aktifkan YouTube Data API v3 → buat API key. Jika tidak memahami pengaturan ini, kosongkan saja — pencarian tetap berjalan normal.

Audio API (background playback)

Sumber audio dicoba berurutan: LOCAL → savenow.to → Vercel → player YouTube. Kosongkan kolom untuk kembali ke bawaan.

Untuk memakai API sendiri: isi URL endpoint milikmu yang menerima ?url= (URL video YouTube) dan merespons {success, formats[]}, atau gaya ?id= dengan {status, audioUrl} — lalu tekan Tes untuk memastikan.
