Blog ini sekarang mendukung postingan berbasis **Markdown**. Cukup tulis file `.md` di folder `content/`, tambahkan *front matter* di bagian atas, dan daftarkan di `content/index.json`.

## Format Front Matter

```markdown
---
title: Judul Postingan
date: 2026-10-04
tags: [tag1, tag2]
description: Ringkasan singkat postingan.
---
```

Isi markdown di bawah garis `---` kedua akan di-render otomatis menjadi artikel.

## Yang Bisa Dipakai

- **Tebal**, *miring*, dan `kode inline`
- Daftar bullet dan numbered list
- [Link](https://craxid.github.io) dan gambar
- Code block dengan highlight sederhana
- Quote:

> Tulis sekali, tampil rapi di semua tema.
